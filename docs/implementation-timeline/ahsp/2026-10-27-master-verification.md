# 27 Oktober 2026: rekonsiliasi master dan rincian analisis

Seluruh 11.541 versi katalog Supabase dibandingkan dengan ekspor item/komponen SIPASTI. ID ekspor hanya dipakai untuk pengelompokan; regulasi, kode/nama, bidang, dan satuan menentukan pasangan. Penerapan batch dan pembacaan ulang menghasilkan 8.763 Verified dan 2.778 Need re-verified. Rincian dilengkapi pada 10.189 versi non-SMKK; data harga tidak diimpor.

UI kini menggunakan dua label berwarna serta alasan pemeriksaan di modal. Variabel dan keterangan JSON tersedia pada rincian komponen. Status asal lama tetap menjadi riwayat internal. Dua migrasi menambahkan jejak sebelum/sesudah dan validasi satuan tenaga SIPASTI pada MPTK. Identitas, basis analisis, dan rujukan PDF dipertahankan.
