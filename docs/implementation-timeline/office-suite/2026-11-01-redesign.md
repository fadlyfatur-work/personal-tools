# Redesain Office Tools dan perbaikan UX

Tanggal: 1 November 2026. Status: diterapkan dan pemeriksaan tanpa browser selesai.

## Hasil
- Identitas Office Tools bertahan dari /menu ke seluruh aplikasi. Sidebar datar menggantikan sambutan dan kartu navigasi bertingkat; lokasi aktif dan tautan kembali tetap tersedia.
- Judul dan workspace disatukan. Kontrol, formulir, status, daftar, tabel dan panel menggunakan ukuran, bentuk serta token yang konsisten pada Office, Change Tracker, Health Dashboard dan pengelolaan akun.
- Daftar Office berupa baris dalam satu panel; pilihan catatan diumumkan dengan aria-pressed. Editor tetap menggunakan state dan kontrak penyimpanan sebelumnya.
- Documents: gerbang PIN terfokus dengan keterangan 5-12 angka, bar kelompok aktif, filter dua kolom, katalog lebar penuh, serta perbedaan koleksi kosong dan pencarian tanpa hasil. Hapus filter mereset kedua filter serta offset.
- Admin template menempatkan kelompok/daftar dan editor secara berdampingan pada layar lebar, lalu bertumpuk pada layar sempit. Pilihan template memakai aria-pressed.
- Stylesheet sisipan Quill dihapus; geometri dan fokus editor dimiliki CSS Documents dengan token bersama.

## Dasar dan batas
Lihat [audit lima temuan dan kontrak UX](../../superpowers/plans/2026-11-01-office-tools-redesign.md). Pemeriksaan dilakukan dari kode aktual, render statis dan simulasi interaksi; bukan riset pengguna. Tidak menambah library UI, data contoh, migrasi atau endpoint. Izin admin, PIN per kelompok, uji/penerbitan versi dan isolasi FinTrack tetap memakai kontrak yang sudah ada. AHSP dan perubahan lain yang telah ada dalam checkout tidak termasuk hasil tugas ini.

## Verifikasi
- Lulus: test-suite-frame, test-tools-ui, test-tools-theme, test-tools-auth, test-tools-admin, test-office-session, test-documents-ui, test-documents-catalog (node scripts/<nama>.mjs).
- Lulus: npm run typecheck dan scoped ESLint untuk seluruh TSX/skrip yang diubah.
- Kontras pasangan teks/aksi token terang, gelap dan sistem gelap minimum 5.26:1. Bukan pengukuran semua piksel hasil render.
- Build pertama berhasil kompilasi dan TypeScript tetapi ditolak EPERM saat membuat folder /document. Pengulangan dengan izin yang sesuai berhasil menghasilkan 52 halaman; build final setelah koreksi Quill juga lulus (npm run build -- --webpack, exit 0, 52 halaman statis).
- Tanpa tes browser atau Lighthouse sesuai instruksi pengguna. Tidak mengklaim verifikasi visual viewport, pixel fidelity, CWV, atau kondisi database produksi baru.

## Pemeliharaan
SuiteFrame memiliki navigasi dan heading; tools.module.css memiliki komponen akun/operasi; office.module.css memiliki daftar/detail Office; documents.module.css memiliki katalog, PIN, admin dan editor Word. Perubahan berikutnya pada geometri atau tema harus diperiksa pada pemilik tersebut, tanpa stylesheet sisipan per editor. Lihat [panduan suite](../../office-suite.md).
