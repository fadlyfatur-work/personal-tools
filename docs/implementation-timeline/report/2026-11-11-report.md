# Tambah laporan ASB harian

Tanggal: 11 November 2026. Status: implementasi lokal; aktivasi schema/PIN/data sumber pada Supabase live memerlukan SQL manual.

Menambahkan `/report` dan tautan menu untuk memelihara laporan 38 provinsi berdasarkan sumber PDF 10 November 2026. Tabel bertingkat memakai hijau untuk selesai/akun Ada dan biru pucat untuk belum selesai, dengan teks T/C/N/D yang mempertahankan ketidakpastian data sumber.

Fitur mencakup PIN admin/penginput terpisah, edit checklist dan angka, rincian akun serta paket, timestamp server, snapshot/revisi per tanggal, grafik, impor/template Excel dan PDF A3 dengan lampiran. Penyimpanan memakai dokumen JSON harian tervalidasi, transaksi revisi/audit dan akses database server-only. Tidak menambah dependensi runtime atau mengubah modul lain di checkout.

Review independen menemukan salah tanggal setelah GET gagal dan pembatasan ZIP yang semula percaya metadata. Keduanya diperbaiki dengan regresi: snapshot lama dikosongkan saat memuat tanggal dan dekompresi native dibatasi selama streaming. Penyelesaian integrasi memakai jumlah tepat; waktu progres yang benar-benar diketahui dipertahankan untuk pengurutan.

Verifikasi: assertion domain/API/berkas, PostgreSQL terisolasi, TypeScript, lint berkas report, serta browser 1440/390/320 piksel pada tema terang/gelap. Browser memeriksa 38 baris, 228 checklist, edit/simpan paket, perlindungan draft, kegagalan pindah tanggal, grafik, parser Excel browser dan PDF. PDF rekap utama dirender dan diperiksa.

Uji UI memakai intersepsi jaringan khusus konteks pengujian; tidak menulis ke database live. Build produksi `npm run build -- --webpack` berhasil; build default Turbopack gagal menjalankan proses PostCSS pada lingkungan ini, termasuk sesudah dicoba di luar sandbox. Script build proyek tidak diubah. Aktivasi dijelaskan pada [panduan fitur](../../report.md). Nilai PIN tidak dicatat dalam dokumentasi atau kode sumber; disiapkan melalui file lokal yang diabaikan Git sesuai instruksi pemilik.

Data seed dipisahkan dari model yang dipakai browser dan hanya dikirim melalui API setelah pemeriksaan PIN. Kontras teks status/tombol/header yang diperiksa berkisar 5,03:1 sampai 9,14:1 pada pasangan warna yang digunakan. Tidak ada dependensi produksi baru.

Keputusan: memakai checkout aktif karena dependensi Office Tools sudah ada dalam perubahan lokal; tidak membuat worktree atau commit baru. Urutan progres ditafsirkan sebagai jumlah langkah paket selesai, tahap akun, waktu awal, lalu urutan sumber. Perbaikan tidak diperlakukan sebagai penambah skor.

## Penyesuaian lanjutan — 17 November 2026

Catatan analisis/kendala dan tindak lanjut kini disimpan sebagai riwayat per provinsi dengan timestamp server, dari tombol di modal provinsi. Status Perbaikan tidak mewajibkan catatan paket. PDF lampiran mencantumkan riwayat catatan; warna status web dan PDF memakai hijau dan biru yang lebih jelas.

Modal provinsi/akun dapat langsung mengedit dan menyimpan; sel tahap 4 hanya menampilkan ikon pembuka rincian. Rekap PDF mencantumkan jumlah provinsi berakun untuk tiap peran, tanpa catatan cakupan maupun label sumber yang diminta dihapus.

Penyegaran UI memakai tint hijau/biru, kuning untuk T/C, dan abu-abu berkontras untuk N/D. Tabel mendapat filter tahap/status, progress bar integrasi, badge posisi akun, nama paket ellipsis dengan tooltip, sticky No/Provinsi, zebra/hover, dan legenda berikon. Rumus progres keseluruhan tetap tidak dibuat.
